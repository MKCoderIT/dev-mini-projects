# 🚀 Dev Mini Projects

A collection of **small development projects** built for learning, practicing, and improving web development skills.  
Each project focuses on a specific concept — from UI design and animations to API integration and backend logic.

---

## 🎯 Purpose

This repository serves as a **personal sandbox** for experimenting with different tools, frameworks, and techniques across frontend and backend development.  
It’s meant to document progress, build confidence, and explore new technologies through hands-on coding.

---

## 📁 Structure


- **frontend/** → mini UI projects, React apps, and design experiments  
- **backend/** → small APIs, authentication systems, and CRUD logic demos
